# Project Automation Rule: Always Sync to GitHub

Whenever any modification, fix, styling adjustment, or new asset is added to this project:
1. Always commit the changes: `& "D:\Git\cmd\git.exe" add .`
2. Write a clear descriptive commit message: `& "D:\Git\cmd\git.exe" commit -m "<Description of changes>"`
3. Push immediately to the remote repository on GitHub: `& "D:\Git\cmd\git.exe" push origin main`
4. Confirm to the user that the changes are live on https://github.com/Ahmad1259/Sidraa-Salon-
